# Portfolio Analysis

## Project Context: 
- This project answers the question "How well am I actually investing?"
- It rebuilds what I owned since the day that I started investing in December 2024, it calculates my portfolio's value each day and measures: return, adjusted for my deposits and withdrawals, risk (volatility and maximum drawdown), and risk-adjusted return.
- It compares my portfolio against indexes like S&P 500/FTSE 100
- Next, I’ll use the same tool on my UMushroom and university competition portfolios.

## Tools used: 
- Python 3.9 (programming language that everything is written in)
- Pandas (Loading, cleaning and analysing the transaction data)
- Numpy (Maths on numbers)
- matplotlib (Charts, such as portfolio's value, drawdowns, me against the benchmark)
- yfinance (Downloading daily share prices and index data from Yahoo Finance)
- Jupyter Notebook  (writing code step by step)
- VS Code 
- Git & Github (Version control and publishing the project)
- venv (Keeps this project's libraries separate from the rest of my Mac)


## Data:
- Uses my own Trading 212 transaction export. The raw data is not included in this repository for privacy reasons.
